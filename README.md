# 🩺 Dr Plus - Clinic Management System

A modern Windows desktop clinic management system built with **React**, **Electron**, **Node.js**, and **TypeScript** to streamline daily clinic operations.

---

## 📋 Overview

Dr Plus is a desktop application designed for medical clinics and private practices. It provides separate workspaces for doctors and secretaries, helping manage patients, appointments, electronic medical records, billing, reporting, and AI-assisted medical workflows.

The application is built using modern web technologies and packaged as a native Windows desktop application with Electron.
